GitHub

The app's GitHub connection is the local side of the bridge: it watches the configured repository for ChatGPT requests, runs approved tools on your Windows machine, and commits their real results back to the repository. This is separate from ChatGPT's existing GitHub integration. The app's token is encrypted using Windows secure credential storage and is never sent to ChatGPT.

Create an OAuth App in GitHub Developer settings and enable Device Flow. Authorization requests repo and read:user scopes. Review the requested access before approving.
