The Windows worker needs repository access so it can read queued requests and write tool results and heartbeat state. This app-side credential is separate from ChatGPT’s GitHub integration.

Authenticate the local worker

Use a GitHub OAuth App with Device Flow enabled. Authorization requests repo and read:user. Review the permission screen before approving. The access token is encrypted with Windows-backed Electron secure storage and never inserted into ChatGPT messages or mailbox files.

Create/configure this in GitHub Developer settings and enable Device Flow. Do not paste an access token or password here.

Why this is separate

Your existing ChatGPT conversation uses the ChatGPT GitHub integration to create request files and inspect results. The Windows app uses its own OAuth grant to poll the same branch and commit results. The shared repository is the mailbox; this app does not mirror or host your ChatGPT conversation.
