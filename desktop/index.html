Safety and ChatGPT connection

ChatGPT does not need a separate login inside this app. Use your normal ChatGPT conversation and its GitHub integration to create requests and read results. The app never injects tool output into that conversation. Normal ChatGPT web sign-in has no callback to this worker, so use Alt+Tab to return after signing in; the bridge does not access ChatGPT credentials or conversations.

File changes, shell commands, tests, Git writes, and file uploads require a native Windows approval prompt. Approved PowerShell commands run with your Windows account permissions and are not sandboxed.

Use a private mailbox. Never send secrets or private data through the repository.

Ctrl + Shift + Space toggles the compact orb · ChatGPT remains the place you type instructions.
