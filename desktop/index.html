IMPORTANT

Permission boundaries

!
Approvals stay local

Remote request files cannot silently authorize writes or shell execution. Approve each risky operation in the Windows dialog.

PowerShell is not sandboxed

An approved command runs with your Windows user’s permissions and may access files outside the selected workspace.

Repository visibility matters

The app warns before enabling a public repository as a mailbox. Sanitization reduces accidental disclosure but is not a substitute for a private repository.
