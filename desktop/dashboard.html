Embedded browser

Page focus compatibility and memory trade-offs.

Opt-in mode disables Chromium background throttling and reports document visibility/focus as active. It does not focus the native app window or synthesize user input; some sites may use other focus signals.

Both options can be enabled together: focus compatibility applies to the active page, while low-memory mode unloads inactive tabs. A page that is unloaded cannot keep running. 100 MB is a best-effort target, not a guaranteed cap; Colab and Chromium can exceed it.
