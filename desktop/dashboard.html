Embedded browser

Disabled by default to prevent web content from interfering with app controls and input fields.

When disabled, embedded web views are closed and cannot cover app controls. Open web links in your normal browser instead. Enabling this allows web tabs inside the app.

Opt-in mode disables Chromium background throttling and reports document visibility/focus as active. It does not focus the native app window or synthesize user input; some sites may use other focus signals.

Inactive web tabs are closed when you minimize the main window to the tray. They retain their tab references and reopen when selected; active Colab computations may stop if its view is destroyed. 100 MB is a best-effort tab target, not a guaranteed cap.
